# Obsidian Read It Later

Obsidian 用の「後で読む」リンク管理プラグインです。

[OneTab](https://www.one-tab.com/) のリンクをクリックするとそのままタブが閉じられる操作感を Obsidian 上で再現したくて作りました。リンクを一箇所に保存しておき、読んだらクリックするだけで自動的に既読に移動します。

## 機能

- **クリップボードからリンクを追加** — コマンド一発でページタイトルを自動取得して保存
- **クリックで既読に移動** — リンクを開くと同時に自動アーカイブ（Reading Mode / Live Preview 両対応）
- **複数 URL の一括追加** — 複数行の URL をまとめて貼り付け可能
- **`URL | タイトル` 形式に対応** — タイトル付き形式はフェッチなしで即保存
- **重複スキップ** — 未読に同じ URL が既にある場合は追加しない
- **既読を一括削除** — アーカイブ済みリンクをコマンドで全削除

## 保存形式

リンクは指定した Markdown ファイルに保存されます。

```markdown
## 未読
- [ ] [記事タイトル](https://example.com) <!-- 2026-05-11 10:30:00 -->

## 既読
- [x] [読んだ記事](https://example.com/old) <!-- 2026-05-10 09:00:00 -->
```

## インストール（BRAT 経由）

[BRAT](https://github.com/TfTHacker/obsidian42-brat) を使ってベータ版プラグインとしてインストールできます。

1. BRAT プラグインを Obsidian にインストール・有効化する
2. コマンドパレットから `BRAT: Add a beta plugin` を実行
3. 以下のリポジトリ URL を入力する
   ```
   mint149/obsidian-ril
   ```
4. 「Add Plugin」をクリックし、プラグインを有効化する

## 使い方

### リンクを追加する

コピーしたい URL をクリップボードにコピーし、コマンドパレットから以下を実行します。

```
Read It Later: Add link from clipboard
```

複数行の URL もそのまま貼り付けられます。以下の形式に対応しています。

| クリップボードの形式 | 動作 |
|---|---|
| `https://example.com` | ページにアクセスしてタイトルを自動取得 |
| `https://example.com \| タイトル` | 指定タイトルをそのまま使用（ネットワーク不要） |
| `[タイトル](https://example.com)` | Markdown リンクからタイトルと URL を取得（ネットワーク不要） |
| `  - [ ] [タイトル](https://...)` | 先頭のインデント・バレット・チェックボックスは無視 |

### リンクを既読にする

管理ファイルを開き、リンクをクリックするだけです。自動的に `## 既読` セクションに移動し、ブラウザでページが開きます。

### 既読をすべて削除する

コマンドパレットから以下を実行します。

```
Read It Later: Clear all archived links
```

## 設定

| 設定項目 | 説明 | デフォルト |
|---|---|---|
| 保存ファイル | リンクを保存する Markdown ファイルのパス（Vault ルートからの相対パス） | `ReadLater.md` |
